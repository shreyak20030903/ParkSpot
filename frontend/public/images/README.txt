Photos for the buildings go in this folder.

Name each file after the building, in lower case with dashes, and save it as .jpg.
If a file is missing, the app shows an illustration instead, so nothing breaks.

Only use photos you are allowed to use (your own, or ones with a licence that permits it, like Unsplash).
